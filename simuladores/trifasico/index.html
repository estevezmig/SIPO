Referencia angular

U₁N = 0°; U₁₂ = 30°. El cambio de referencia gira todos los fasores.

Impedancia por fase

R–L–C en serie: C = 0 significa que no hay condensador. Si L = C = 0, la carga es puramente resistiva.
Z = R + jX. X positivo: inductiva. X negativo: capacitiva. Ambas cantidades están expresadas en ohmios.
Z = |Z| ∠ φ. Ángulo positivo: inductiva; negativo: capacitiva. El intervalo −90° a +90° corresponde a cargas pasivas.

Relaciones y potencias

Convenciones del modelo

En estrella, IL = IF y UL = √3 UF. En triángulo, UL = UF e IL = √3 IF.

Las tres ramas tienen la misma impedancia Z. El neutro ideal en estrella lleva 0 A; el triángulo no tiene neutro. La secuencia de fases es L1–L2–L3. U1N designa la fase de la fuente, incluso cuando la carga se conecta en triángulo. Cambiar la referencia angular equivale a desplazar el origen temporal; no modifica los valores eficaces ni las potencias.

Modelo educativo ideal: régimen permanente, elementos lineales, fuente equilibrada y pérdidas de línea despreciadas. Las escalas de tensión y corriente del gráfico fasorial son independientes.Miguel Estévez Ferreiro
